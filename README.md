# PicCollage Growth Audit

**Live → https://eddieatadapty.github.io/piccollage-flow-rebuild/**

Five ideas to turn more PicCollage users into subscribers, each built into a clickable version of PicCollage's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the topics they pick | +10–20% CR to purchase |
| 02 | Let them make one collage before the paywall | +10–20% CR to purchase |
| 03 | Put 1.8M ratings and the 40% saving where they choose | +10–15% CR to purchase · ARPU +10–15% |
| 04 | Ask for notifications after the paywall, with a reason | +10–15% CR to purchase |
| 05 | One honest offer for people who close it | +5–10% ARPU |

Every price, rating and feature comes from PicCollage's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for PicCollage. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
